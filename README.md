### [DAO – Data Access Object](https://github.com/SandeepEvani/dao)
A unified, interface-agnostic data access layer for Python. Register your data stores once, then `read`, `write`, `upsert`, `copy` and `move` without wiring up each backend by hand. Calls are routed to the right interface from the store and the method signature.

**Highlights:** lazy interface loading · multiple interfaces per store · file-based catalog · typed (`py.typed`)
